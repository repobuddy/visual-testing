Full-page and viewport snapshots

Use page.toMatchImageSnapshot() when the subject is the page itself, not one element.

Take a viewport snapshot

Section titled “Take a viewport snapshot”

It captures the visible viewport of the test page. With a viewport of 1280 by 720, as in the vpv test case, the image is 1280 by 720 pixels. To snapshot several sizes, see Viewports and multiple instances.

Take a full-page snapshot

Section titled “Take a full-page snapshot”

Set fullPage to capture the entire scrollable page:

fullPage is false by default. The image has the width and height of the page content, so content below or to the right of the viewport is in it. With the 1280 by 720 viewport, the example above gives an image of 1280 by 1000 pixels. It works with the Playwright and WebdriverIO providers.

Take full-page auto snapshots

Section titled “Take full-page auto snapshots”

Auto snapshots capture the subject, document.body by default. Set fullPage to capture the whole page instead.

Rules

Section titled “Rules”
  • Call it inside a test, and not in it.concurrent(). Concurrent tests share one iframe and would disturb each other.
  • The snapshotKey cannot contain a dash.

Options that matter

Section titled “Options that matter”

page.toMatchImageSnapshot() takes the same comparison options as the element matcher. See page.toMatchImageSnapshot().
