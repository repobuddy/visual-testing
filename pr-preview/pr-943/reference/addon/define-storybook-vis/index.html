defineStorybookVis

A helper function to configure the Storybook Visual Testing addon in .storybook/main.ts.

Function signature

Section titled “Function signature”

The name is the same value that the no-argument form returns. It is a filesystem path, not a file:// URL.

Usage

Section titled “Usage”

Use the default configuration

Section titled “Use the default configuration”

Call defineStorybookVis() without arguments to use all default settings. It returns the package directory path as a string:

Customize the addon configuration

Section titled “Customize the addon configuration”

Pass an options object to configure how the addon stores snapshots and manages visual testing projects. It returns an object containing the package name and your options, unchanged:

Options

Section titled “Options”

The options parameter accepts a StorybookVisOptions object. The same options are described on defineStorybookVisOptions.

visProjects

Section titled “visProjects”

Configure one or more visual testing projects. Each project has its own snapshot storage settings.

snapshotRootDir

Section titled “snapshotRootDir”

Where snapshots are stored. It can be:

  • A static path string, used for all snapshots.
  • A function that receives { ci: boolean; platform: string } and returns the directory.
  • undefined, which uses the default snapshot root directory.

With the function above, { ci: true, platform: 'linux' } gives __vis__/linux, and { ci: false, platform: 'darwin' } gives __vis__/local.

snapshotSubpath

Section titled “snapshotSubpath”

Transform the default snapshot subdirectory path. It receives { subpath: string } and returns the transformed subpath.

With the function above, a subpath of test/path becomes custom/test/path.
