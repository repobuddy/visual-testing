setAutoSnapshotOptions

setAutoSnapshotOptions configures visual snapshot testing options for the current test or test suite.

Usage

Section titled “Usage”

Call it in beforeAll, beforeEach, or inside an individual test:

It accepts either a boolean or an options object.

How options merge

Section titled “How options merge”

The options set at different levels are merged, and the more specific level wins. These results are asserted by the spec:

  • Passing an options object turns snapshots on: the result contains enable: true.
  • setAutoSnapshotOptions({ enable: false }) in a test turns snapshots off for that test and keeps the other merged options.
  • setAutoSnapshotOptions(false) in beforeAll disables snapshots for the file, and setAutoSnapshotOptions({ enable: true }) in a test overrides that.
  • You can add your own keys, for example setAutoSnapshotOptions({ foo: 'bar' }). They are kept in the merged options.

Options

Section titled “Options”

enable

Section titled “enable”

Controls whether auto snapshots are taken for the test.

subject

Section titled “subject”

The CSS selector of the element to snapshot.

If it is not provided, or the element is not found, document.body is used. If the selector matches multiple elements, the first visible one is used. If it matches only hidden elements, the snapshot fails right away with a “not visible” error instead of waiting for the timeout.

snapshotKey

Section titled “snapshotKey”

Customizes the snapshot key.

A key that contains a dash throws Snapshot key cannot contain dash.

timeout

Section titled “timeout”

The timeout for taking the snapshot, in milliseconds. The default is 30000.

comparisonMethod

Section titled “comparisonMethod”

The comparison algorithm: 'pixel' (the default) or 'ssim'.

failureThreshold and failureThresholdType

Section titled “failureThreshold and failureThresholdType”

The tolerance before a test is considered failed. failureThresholdType is 'pixel' (the default) or 'percent'.

expectToFail

Section titled “expectToFail”

Expects the snapshot comparison to fail. Useful for testing that changes are detected.

Unverified

The spec for this function asserts the merge behavior above, enable, the boolean shorthands, subject, comparisonMethod: 'ssim' with diffOptions: { ssim: 'fast' }, failureThreshold, diffOptions: { threshold }, and the snapshot key dash check. It does not assert the timeout default, the hidden-subject failure, failureThresholdType, the pixel diffOptions fields other than threshold, or expectToFail for auto snapshots.
