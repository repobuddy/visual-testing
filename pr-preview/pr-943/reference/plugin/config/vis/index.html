vis (config)

vis from vitest-plugin-vis/config is the Vitest plugin of vitest-plugin-vis. This is not the same vis as the setup object exported from vitest-plugin-vis/setup.

vis() works with zero config. The options below customize its behavior. See also the config overview for how the snapshot path is built.

Unverified

The spec for this page checks that each option below is accepted and stored, and the preset behavior. It does not check default values, the fields of the snapshotRootDir context, how the options change the comparison, or reviewImage. Statements about those come from the original documentation.

preset

Section titled “preset”

The preset option sets up a typical visual testing strategy.

auto

Section titled “auto”

auto is the default preset. It takes a snapshot of the page at the end of each rendering test. It adds vitest-plugin-vis/presets/auto to test.setupFiles.

When you pass an options object without preset (for example vis({})), no preset is applied and test.setupFiles stays empty.

manual

Section titled “manual”

The manual preset does not take any snapshot automatically. It adds vitest-plugin-vis/presets/manual to test.setupFiles.

See expect().toMatchImageSnapshot() on how to take an image snapshot manually.

custom

Section titled “custom”

The custom preset is for advanced users. It adds no setup file and takes no snapshot automatically. You set up your own visual testing strategy in vitest.setup.ts.

Use vis.setup() from vitest-plugin-vis/setup in vitest.setup.ts.

subject

Section titled “subject”

snapshotKey

Section titled “snapshotKey”

snapshotKey specifies the key of the auto snapshot. The default is auto.

A key that contains a dash is rejected when the plugin loads, with the error Snapshot key cannot contain dash. Use alphanumeric characters and underscores.

comparisonMethod

Section titled “comparisonMethod”

comparisonMethod specifies the comparison method: 'pixel' (the default) or 'ssim'.

diffOptions

Section titled “diffOptions”

diffOptions specifies the options of the comparison. What it accepts depends on comparisonMethod.

SSIM comparison

Section titled “SSIM comparison”

If your images have gradients, shadows, or anti-aliasing, SSIM (Structural Similarity Index) might be a better fit. It is designed to match how humans perceive image differences, which means fewer false positives when minor rendering differences do not matter.

For option details, see the ssim documentation. The ssim.js repository is archived, so an issue with ssim comparison may not be fixed.

Failure thresholds

Section titled “Failure thresholds”

A failure threshold sets how much difference is acceptable before a test fails. failureThresholdType is 'pixel' (the default) or 'percent'.

Review image

Section titled “Review image”

When a snapshot mismatches, vitest-plugin-vis writes a review image (<name>.review.png) next to the diff image. It places the baseline, result, and diff crops of each changed region side by side, so you or a coding agent can see what changed without opening the full images. The changed regions are also written to <name>.regions.json. See expect().toMatchImageSnapshot() for details.

Timeout

Section titled “Timeout”

The timeout option sets the default timeout of a snapshot, in milliseconds. The default is 30 seconds.

shortenLongSnapshotPaths

Section titled “shortenLongSnapshotPaths”

When true, paths that would exceed Windows-safe limits are shortened. The default is false. The final path segment is replaced with {firstToken}-{hash12}{ext} when the full path length reaches 250 or a segment is longer than 255. snapshotRootDir itself is not rewritten.

The spec checks only that the option is accepted. The description comes from the doc comment of the option in the source.
