Automatic snapshots

Use automatic snapshots when you want every test that renders something to be covered, with no matcher in the test.

Turn it on

Section titled “Turn it on”

The auto preset is the default of vis():

The preset adds vitest-plugin-vis/presets/auto to test.setupFiles. That file calls vis.setup({ auto: true }). When you pass an options object without preset, such as vis({ failureThreshold: 1 }), no preset applies and no snapshot is taken. Write vis({ preset: 'auto', failureThreshold: 1 }) to keep it.

What happens

Section titled “What happens”

After each test body, the plugin looks at document.body. If it has a child element, the plugin takes a snapshot of the body and compares it with the baseline. A test that renders nothing gets no snapshot.

Choose the element

Section titled “Choose the element”

By default the whole body is the subject. To snapshot one element for every test, set subject to a selector:

To change it for one file or one test, call setAutoSnapshotOptions():

If the selector matches nothing, the body is used. If it matches several elements, the first visible one is used.

Turn it off for some tests

Section titled “Turn it off for some tests”

setAutoSnapshotOptions({ enable: true }) in a test turns it back on for that test.

Decide per test

Section titled “Decide per test”

To decide in one place, use the custom preset and your own setup file. The function gets the snapshot options of the test, including any field you set with setAutoSnapshotOptions():

The function runs after the test body and takes the snapshot unless it returns false. See vis.setup().

Options that matter

Option Where Page
preset, subject, snapshotKey vis() vis config
enable, subject, thresholds, timeout setAutoSnapshotOptions() setAutoSnapshotOptions
auto as a function or as themes vis.setup() vis setup
