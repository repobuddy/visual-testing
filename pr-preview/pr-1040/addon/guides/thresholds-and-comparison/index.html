Thresholds and comparison for stories

Goal: stop tiny render differences, such as anti-aliasing, from failing a story, without hiding real changes. What a threshold is, and how pixel comparison differs from SSIM, is explained in Comparison and thresholds. This page shows where to set them for stories.
