defineStorybookVisOptions

A helper function to define options for the Storybook Visual Testing addon. It returns the options you pass in, which gives you type checking and completion.

Function signature

Section titled “Function signature”

Options

Section titled “Options”

visProjects

Section titled “visProjects”

Configure one or more visual testing projects. Each project can have its own snapshot storage settings.

snapshotRootDir

Section titled “snapshotRootDir”

Where snapshots are stored. It can be:

  • A static path string, used as is for all snapshots. Unlike the Vitest plugin, the addon does not add local or the platform to it.
  • A function that receives { ci: boolean; platform: string }. ci is whether the code runs in a CI environment, and platform is the platform string (for example linux, darwin, win32).
  • undefined, which uses the default snapshot root directory: __vis__/<platform> in CI and __vis__/local elsewhere.

snapshotSubpath

Section titled “snapshotSubpath”

Transform the default snapshot subdirectory path to match your project structure. It receives { subpath: string } and returns the transformed subpath. subpath is the story file’s import path as Storybook reports it, such as ./src/button.stories.tsx. The default removes the leading ./ and a leading common folder (src, source, test, tests, lib, js or ts).

shortenLongSnapshotPaths

Section titled “shortenLongSnapshotPaths”

Shortens snapshot paths that would be too long, the same way the shortenLongSnapshotPaths option of the Vitest plugin does. It defaults to false.

Snapshot path structure

Section titled “Snapshot path structure”

The final snapshot path is constructed as:

  • snapshotRootDir is determined by the snapshotRootDir option.
  • snapshotSubpath is the result of the snapshotSubpath function, or the default.
  • task-id is the story name in lowercase, with every character other than a letter or digit replaced by -.
  • variant identifies the specific snapshot variant.
