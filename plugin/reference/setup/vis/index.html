vis (setup)

The vis object from vitest-plugin-vis/setup provides the API to set up the plugin on the client side. This is not the same vis as the Vitest plugin exported from vitest-plugin-vis/config.

vis is a VisClientConfigurator, an object with one method, setup(options?). The options have the type SetupVisOptions: auto, createMissingBaseline, animations and fullPage. animations: 'disabled' is the default for all auto snapshots; see animations. fullPage: true makes every auto snapshot capture the whole page instead of the subject; see fullPage.

Basic setup

Section titled “Basic setup”

With vis.setup({ auto: false }), a test that renders content takes no auto snapshot, and page.hasImageSnapshot({ snapshotKey: 'auto' }) returns false for it.

Conditional auto snapshots

Section titled “Conditional auto snapshots”

Pass a function to auto to decide for each test whether to take the snapshot. The function receives the snapshot options of the test, including any custom fields you set with setAutoSnapshotOptions(). It takes the snapshot unless the function returns false.

The function is called in afterEach(), after the test body has run.

Theme snapshots

Section titled “Theme snapshots”

Pass an object to auto to take one snapshot per theme. Each key is a theme name, and each value is a handler that prepares the page for that theme. A handler receives the snapshot options of the test, and returns false to skip its theme.

The Themes guide covers the file names, skipping a theme, naming rules and how failures are reported.
