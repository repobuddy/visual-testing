This section compares this project with other visual testing tools.
Each tool has its own page: what it is, what it does better, what this project does better, and when to choose it.

Every claim about another tool comes from that tool's documentation, with a link and the date we read it.
The tools change, so check the linked page before you decide.
If a claim is out of date, [open an issue](https://github.com/repobuddy/visual-testing/issues).

## Matrix

"Not documented" means the tool's documentation page that we read does not mention the feature.
