Capture and compare image snapshots automatically and manually, in Storybook and in Vitest Browser Mode.

| Package | What it is for | npm | Docs |
| ------- | -------------- | --- | ---- |
| `storybook-addon-vis` | Capturing and comparing image snapshots of your stories, automatically and manually, from [Storybook Vitest addon](https://storybook.js.org/docs/writing-tests/integrations/vitest-addon) tests. | [npm](https://www.npmjs.com/package/storybook-addon-vis) | [Storybook addon](/visual-testing/addon/) |
| `vitest-plugin-vis` | Capturing and comparing image snapshots in tests that run in [Vitest Browser Mode](https://vitest.dev/guide/browser), without Storybook. | [npm](https://www.npmjs.com/package/vitest-plugin-vis) | [Vitest plugin](/visual-testing/plugin/get-started/) |

## Which one do I need

If you test your stories with Storybook, use `storybook-addon-vis`. It uses `vitest-plugin-vis` internally to do the heavy lifting.
If you do not use Storybook and write tests in Vitest Browser Mode directly, use `vitest-plugin-vis`, which was extracted from the addon to be used directly in Vitest.

## Storybooks

The repository's Storybooks are published with this site:

- [Addon Storybook](/visual-testing/storybook/): the Storybook of `storybook-addon-vis` itself.
- [Themes](/visual-testing/examples/themes/storybook/): one set of snapshots per theme.
- [Multi instances](/visual-testing/examples/multi-instances/storybook/): one set of snapshots per browser viewport.
- [CSF Next](/visual-testing/examples/sb-csf-next/storybook/): stories written in CSF Next.

They only render the stories. Snapshots are taken while Vitest runs them. See [Examples](/visual-testing/addon/examples/).
