This page is an index.
Each row names a capability and links to the page that shows how to use it.
The concepts behind them are in [Visual testing](/visual-testing/visual-testing/what-is-visual-testing/).

## Taking snapshots

| Feature | In one line | Guide |
| --- | --- | --- |
| Automatic snapshots | Every story with the `snapshot` tag is captured at the end of its test. | [Automatic snapshots](/visual-testing/addon/guides/automatic-snapshots/) |
| Per-story opt out | `!snapshot` turns a story off, like `!test`. | [Automatic snapshots](/visual-testing/addon/guides/automatic-snapshots/) |
| Manual snapshots | `expect(element).toMatchImageSnapshot()` in a `play` function, on the page or on one element. | [Manual snapshots](/visual-testing/addon/guides/manual-snapshots/) |
| Existence check | `hasImageSnapshot()` tells a story whether its baseline exists. | [Manual snapshots](/visual-testing/addon/guides/manual-snapshots/#check-if-a-snapshot-exists) |
| CSF Next | Setup in the preview with `addonVis()`, and snapshots of stories with `story.test()`. | [CSF Next and story.test()](/visual-testing/addon/guides/csf-next/) |
| Chrome DevTools Protocol | `cdp()` works inside stories under Playwright and Chromium. | [Chrome DevTools Protocol](/visual-testing/addon/guides/chrome-devtools-protocol/) |

## Comparing and reviewing

| Feature | In one line | Guide |
| --- | --- | --- |
| Thresholds | Tolerate a number or percentage of different pixels, globally, per story or per call. | [Thresholds and comparison](/visual-testing/addon/guides/thresholds-and-comparison/) |
| Pixel and SSIM comparison | Pick the algorithm per project, story or call. | [Thresholds and comparison](/visual-testing/addon/guides/thresholds-and-comparison/) |
| Vis panel | Baseline, result and diff of a story inside Storybook, with swipe and onion skin. | [The Vis panel](/visual-testing/addon/guides/the-vis-panel/) |
| Review image | A failure writes a side-by-side crop of each changed region and a regions file. | [Reviewing failures](/visual-testing/addon/guides/reviewing-failures/) |
| Agent review | A skill and an `llms.txt` help coding agents read failures cheaply. | [Reviewing failures with agents](/visual-testing/visual-testing/reviewing-failures-with-agents/) |
