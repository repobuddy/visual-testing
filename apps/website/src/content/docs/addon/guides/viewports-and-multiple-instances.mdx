Goal: one baseline per story for each viewport or browser.
The idea is in [Variations](/visual-testing/visual-testing/variations/).

## Set up

Vitest browser mode runs each entry of `browser.instances` as its own project.
Name every instance, and put the project name in the snapshot root so the instances do not overwrite each other:

```ts
// vitest.config.ts
import { storybookVis } from 'storybook-addon-vis/vitest-plugin'

export default defineConfig({
	plugins: [
		storybookTest(),
		storybookVis({
			snapshotRootDir({ ci, platform, projectName }) {
				return `__vis__/${ci ? platform : 'local'}/${projectName}`
			},
		}),
	],
	test: {
		browser: {
			enabled: true,
			provider: playwright(),
			instances: [
				{ browser: 'chromium', name: 'HD', viewport: { width: 1280, height: 720 } },
				{ browser: 'chromium', name: 'SVGA', viewport: { width: 800, height: 600 } },
			],
		},
		setupFiles: ['./.storybook/vitest.setup.ts'],
	},
})
```

This is the `multi-instances` test case.
See the [Multi instances example](/visual-testing/addon/examples/multi-instances/).

## What appears on disk

```text
__vis__/linux/HD/__baselines__/story_snapshot.stories.tsx/primary-light.png
__vis__/linux/SVGA/__baselines__/story_snapshot.stories.tsx/primary-light.png
```

The same works for different browsers: add an instance per browser and keep the name in the path.

## Show the snapshots in the Vis panel

The panel finds images through `visProjects` in `.storybook/main.ts`, not through the Vitest config.
Add one entry per instance, and set `projectName` on each so the same `snapshotRootDir` function gives the same folder:

```ts
// .storybook/main.ts
import { defineStorybookVis } from 'storybook-addon-vis/node'

const snapshotRootDir = ({ ci, platform, projectName }: { ci: boolean; platform: string; projectName?: string | undefined }) =>
	`__vis__/${ci ? platform : 'local'}/${projectName}`

export default {
	addons: [
		defineStorybookVis({
			visProjects: [
				{ projectName: 'HD', snapshotRootDir },
				{ projectName: 'SVGA', snapshotRootDir },
			],
		}),
	],
}
```

See [Monorepos and custom snapshot paths](/visual-testing/addon/guides/monorepo-and-paths/).
