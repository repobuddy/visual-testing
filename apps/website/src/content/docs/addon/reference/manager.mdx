Storybook loads `storybook-addon-vis/manager` in the browser UI when you add the addon.
You do not import it yourself.

It registers the addon and, in development mode only, adds the **Vis** panel to the story view.
Static builds get no panel.

It exports no names.
For what the panel shows, see [The Vis panel](/visual-testing/addon/guides/the-vis-panel/).
The server side is the [preset entry](/visual-testing/addon/reference/preset/).
