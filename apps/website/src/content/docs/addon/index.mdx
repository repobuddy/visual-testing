[storybook-addon-vis](https://www.npmjs.com/package/storybook-addon-vis) performs self-contained visual testing for [Storybook](https://storybook.js.org).
It runs your stories in Vitest browser mode, compares an image of each with a stored baseline, and keeps the images in your repository.

If you do not use Storybook, see the [Vitest plugin](/visual-testing/plugin/get-started/).
[Choosing a package](/visual-testing/visual-testing/choosing-a-package/) compares the two.
