`vitest-plugin-vis/presets/manual` is a setup file.
It has no named export. You import it for its effect.

Its whole content is:

```ts
import { vis } from '../setup.ts'

vis.setup({ auto: false })
```

The effect is that no automatic snapshot is taken, and `expect().toMatchImageSnapshot()` and `page.toMatchImageSnapshot()` are available.

## Use it

`vis()` adds it to `test.setupFiles` when `preset` is `'manual'`:

```ts
// vitest.config.ts
import { vis } from 'vitest-plugin-vis/config'

export default defineConfig({
	plugins: [vis({ preset: 'manual' })],
})
```

To list it yourself, set `preset: 'custom'` and put the file in `test.setupFiles`:

```ts
export default defineConfig({
	plugins: [vis({ preset: 'custom' })],
	test: {
		setupFiles: ['vitest-plugin-vis/presets/manual'],
	},
})
```

See [Manual snapshots](/visual-testing/plugin/guides/manual-snapshots/).
The sibling preset is [`presets/auto`](/visual-testing/plugin/reference/presets/auto/).
