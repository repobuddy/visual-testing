Import `createVis` from `vitest-plugin-vis/setup-api` (not from `vitest-plugin-vis/setup`).

`vitest-plugin-vis/setup` does not export `createVis`.
See [`vis`](/visual-testing/plugin/reference/setup/vis/) for the setup object that `vitest-plugin-vis/setup` exports.
