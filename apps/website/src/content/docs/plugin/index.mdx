[vitest-plugin-vis](https://www.npmjs.com/package/vitest-plugin-vis) performs self-contained visual testing for tests that run in [Vitest Browser Mode](https://vitest.dev/guide/browser).

It takes screenshots through your browser provider, compares them with baseline images in your repository, and writes the differences to disk.
There is no cloud service. The snapshots are files that you commit.

If your components live in Storybook, use [storybook-addon-vis](/visual-testing/addon/) instead.
It runs this plugin for your stories.
[Choosing a package](/visual-testing/visual-testing/choosing-a-package/) compares the two.
