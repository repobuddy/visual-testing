These test cases live in the [`testcases`](https://github.com/repobuddy/visual-testing/tree/main/testcases) folder of the repository.
Their baselines are committed, so you can read the files that a run produces.

| Example | Shows |
| ------- | ----- |
| [vpv](/visual-testing/plugin/examples/vpv/) | The plugin alone, without Storybook: automatic and manual snapshots with options set in `vis()`. |
| [Workspace](/visual-testing/plugin/examples/workspace/) | Two Vitest projects in one repository, each with its own snapshot folder. |

For Storybook examples, see the [addon examples](/visual-testing/addon/examples/).
